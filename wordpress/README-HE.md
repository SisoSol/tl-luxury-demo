# T&L Luxury — חנות WooCommerce

## מה כלול

תבנית חנות בעברית, תוסף לוח ניהול ממוקד, ו־Blueprint להתנסות חינמית ב־WordPress Playground. המוצרים, המידות, המלאי, הקופונים והחשבונות נשמרים במערכת WooCommerce עצמה. אין חיבור סליקה פעיל בדמו.

## להתנסות בניהול

[פתיחת סביבת WordPress ו־WooCommerce](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2FSisoSol%2Ftl-luxury-demo%2Fmain%2Fwordpress%2Fblueprint.json%3Fv%3D2.0.3)

הטעינה הראשונה מתקינה WordPress, WooCommerce, תבנית T&L ותוסף PayPlus הרשמי. המערכת נכנסת אוטומטית לחשבון `manager-one`. החשבון השני הוא `manager-two`. סיסמת ההדגמה לשניהם היא `Demo-TL-2026-Only!`. אלו חשבונות של סביבת הדגמה אישית בדפדפן, לא פרטי גישה לחנות באינטרנט. להחלפת מנהל יוצאים מהחשבון ומתחברים לחשבון השני דרך מסך הכניסה של WordPress.

בלוח **T&L — החנות**:
1. **מוצרים** — פותחים מוצר, משנים מחיר/תמונה/מידות/מלאי ולוחצים עדכון.
2. **קופונים** — יוצרים הנחה באחוזים או בסכום קבוע, מוסיפים תוקף ותנאים.
3. **עמוד הבית** — משנים כותרת, פסקת פתיחה, הודעת אתר ו־WhatsApp בטופס פשוט.
4. **הזמנות** — ניהול הזמנות אמיתי בחנות הפעילה. בדמו אין הזמנות או חיובים אמיתיים.
5. **משלוחים ודוחות** — מסכי WooCommerce הרגילים. נתוני מכירות מופיעים רק כשיש הזמנות אמיתיות.

Playground אינו שרת משותף. כל דפדפן מקבל סביבת ניסיון נפרדת. אפשר לשמור/לייצא אותה דרך כלי Playground; אין להסתמך על דמו הדפדפן כגיבוי לחנות עסקית.

## התקנה בחנות משותפת

1. מתקינים WordPress על אחסון PHP/MySQL עם HTTPS, גיבויים ותחזוקה.
2. מתקינים את WooCommerce הרשמי ומגדירים עברית, ישראל ושקלים.
3. מעלים דרך **עיצוב ← תבניות** את `tl-luxury-theme.zip`, ומפעילים.
4. מעלים דרך **תוספים** את `tl-luxury-tools.zip`, ומפעילים.
5. יוצרים לשני המנהלים חשבונות נפרדים בתפקיד **מנהל חנות / Shop Manager**. סיסמאות וכתובות אימייל אמיתיות נקבעות בחנות — לא משתמשים בסיסמאות הדמו.
6. בוחרים עמוד בית סטטי, יוצרים עמודי מידע ומוצרים דרך מסכי WordPress ו־WooCommerce, ומחליפים את כל תמונות ומפרטי הדמו בתוכן מאושר.
7. מתקינים את [PayPlus Payment Gateway הרשמי](https://wordpress.org/plugins/payplus-payment-gateway/), מחברים חשבון מסחרי ובודקים סליקה בסביבת הבדיקות של הספק.

התוסף אינו מייבא דוגמאות או יוצר משתמשים אוטומטית בחנות אמיתית. פונקציית ההדגמה מופעלת רק כש־`TL_LUXURY_DEMO` מוגדר במפורש; אין להגדיר אותו בחנות הפעילה. מפתחות סליקה נשמרים רק בשרת באמצעות התוסף הרשמי.

## שיווק — מוכן לחיבור, לא מחובר בדמו

WooCommerce כולל מוצרים, קטגוריות, מבצעים מתוזמנים, מלאי, קופונים, הזמנות, ייצוא וייבוא CSV ודוחות. למסחר ב־Google וב־Meta מחברים את התוספים הרשמיים לאחר פתיחת החשבונות. לביצועי קמפיינים מחברים GA4 ואירועי מסחר לאחר בחירת מנגנון הסכמה. דיוור ושחזור סל דורשים בחירת שירות, חיבור ובדיקת משלוח — הם אינם פעילים בדמו.

## אירוח

GitHub Pages מארח בחינם את **הדמו החזותי ללא עסקאות**, לא WordPress, PHP או מסד נתונים. WordPress Playground מאפשר **התנסות אמיתית אך אישית** בניהול. חנות משותפת לשני המנהלים, הזמנות וסליקה מחייבת אחסון WordPress קבוע; WordPress.com החינמי אינו מתקין תוספי WooCommerce. אין מחיר אחסון או עמלת סליקה מובטחים בחבילה הזו.
